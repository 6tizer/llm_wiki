# SPEC-14: UI 信息架构二轮（IA Round 2）

> 类型：阶段 SPEC | 状态：charter draft | 依赖：SPEC-13（Agent 设置/对话页最终形态依赖新模型接入层） | 来源：2026-07-05 用户实测反馈

## 范围（结构性 IA 改动，快赢批之外）

1. **知识库/文件面板右移 + 可折叠**：现左侧固定面板（知识库树/文件）移到右侧，默认可折叠，折叠后点击展开。动 app-layout，全页面受影响；对话页因此成为左起第一视觉主体（Notion 式 chat-centric）。
2. **深度研究归并探索**（已定裁决，2026-07-05）：主导航 5→4，「探索」内 tabs 变为 **图谱 → 搜索 → 深度研究**。理由：图谱看缺口 → 搜索验证 → 深研补齐是天然动线，图谱的一键深研入口已存在。深研长任务运行态用 tab 角标（运行中指示）解决；research-store 与路由 id 不变，仅挂载点迁移。
3. **Wiki 健康中心 Dashboard 化**：流式排布改横向 tabs——首 tab「Dashboard」（健康分/问题发现列表，每项带一键修复或一键跳转对应管理 tab）+「派生状态」「Lint」「审阅」「治理」等管理 tabs。一键修复接现有 derived-rebuild/lint-fix action，不新造执行通道。
4. **对话页 Agent 设置最终形态**：composer「自动 ▾」下拉的模型/用途/权限选择器随 SPEC-13 的「连接」概念重写文案与层级（先连接后权限），消除现在「看不懂」的断层。

## 快赢批（先行 PR，不在本 SPEC 内，2026-07-05 已启动）

模型配置页/流水线治理页 tabs 化、探索图谱前置、nav「Wiki」→「对话」、QA/Agent 栏合并——纯 UI 无行为改动，先行合并立即见效；本 SPEC 的 tabs 骨架复用其成果。

SPEC-13 之后启动（第 4 项硬依赖；第 1-3 项技术上可并行，但按「每个 SPEC 完整完成」纪律不提前开轨）。
